# Qwilr

> Qwilr is a document-experience platform for creating interactive, web-based
> sales proposals, quotes, contracts, and reports. Its REST API and hosted MCP
> server let teams generate branded pages from templates and saved blocks,
> manage quote taxes and payment gateways, subscribe to page-lifecycle webhook
> events, and automate the sales workflow programmatically.

## API
- [Qwilr REST API](https://api.qwilr.com/v1): Base URL for the Qwilr API. Bearer-token (JWT) auth. Enterprise plan with API access required.

## Docs
- [API Documentation](https://docs.qwilr.com/): Qwilr developer documentation home.
- [API Reference](https://docs.qwilr.com/api-reference): Endpoint reference (pages, saved blocks, taxes, payment gateways, webhooks, users).
- [Quick Start](https://docs.qwilr.com/docs/getting-started/quick-start): Get an access token and create your first page.
- [Help Centre](https://help.qwilr.com/): Product help and support.

## MCP
- [Qwilr MCP Server](https://mcp.qwilr.com): OAuth-protected (scope `mcp`) hosted Model Context Protocol server.

## Webhooks
- Events: pageAccepted, pagePartiallyAccepted, pagePreviewAccepted, pageViewed, pageFirstViewed, pageSetLive, pageRevivedLive.
